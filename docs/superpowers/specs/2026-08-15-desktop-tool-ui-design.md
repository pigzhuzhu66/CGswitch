# SwitchGPT 精密桌面工具界面设计

## 目标

将 SwitchGPT 从装饰性 AI SaaS 仪表盘调整为适合高频配置切换的桌面工具界面：当前配置和操作优先，档案信息紧凑、可扫描，状态反馈只在需要时出现。

## 已确认方向

采用“Raycast 的克制、Linear 的信息密度、Zed 的配置语义”。不复制任何产品视觉；只借鉴其布局和交互原则。

## 视觉规则

- 去除页面径向渐变和毛玻璃效果；使用不透明的中性背景与表面。
- 主色收敛为靛蓝，仅用于主操作、当前导航和焦点；绿色只表达成功或运行，红色只表达删除或失败。
- 使用细分隔线和 4–8px 圆角；阴影只用于弹窗，不用于常规面板。
- 保留现有 Inter、系统中文字体和 JetBrains Mono 回退栈，不增加字体或图标依赖。
- 同时维护浅色和深色主题的层级、边框和文本对比度。

## 配置档案页

1. 页面顶部为紧凑上下文栏：显示当前生效档案名称，以及 Codex 运行状态和自动重启状态。
2. 顶部操作保留刷新、捕获当前配置、重启 Codex；主操作使用靛蓝，其他操作为次要样式。
3. 重启进度仅在重启进行中、成功或失败时显示；空闲时不占据页面空间。
4. 档案从大卡片改为带表头的紧凑列表：名称、模型、Provider、推理强度、状态和操作。
5. 当前档案用左侧靛蓝标记、状态标签和弱背景区分；不使用绿色发光或悬浮位移。
6. 删除仍保留现有确认对话框；应用、重命名、删除的禁用与忙碌逻辑不变。
7. 窄窗口继续将列表自然折叠为纵向信息块，不引入新的路由或响应式状态。

## 设置页与全局框架

- 左侧导航简化为产品名和两个文本导航项，使用细边界而非大块紫色按钮。
- 设置页沿用原有字段、保存时机和后端 API；仅压缩圆角、面板和标题层级，使其与档案页一致。
- `theme.ts` 的 Naive UI 覆盖改为靛蓝主色和更小的通用圆角，继续由现有 `NConfigProvider` 应用。

## 不做的事

- 不新增依赖、图标库、命令面板、搜索、路由、数据模型或 API。
- 不改变档案捕获、应用、重启、重命名、删除与设置保存的业务行为。
- 不执行发布构建；完成后按项目规则启动 `pnpm dev:tauri`，由用户人工确认桌面窗口。

## 验收

- 界面不再出现紫绿渐变、毛玻璃、常驻空闲进度条或大面积圆角卡片。
- 当前档案、运行状态和可用操作无需滚动即可辨认。
- 档案在常见桌面宽度下以一行一个档案的紧凑列表展示，并在窄窗口保持可读。
- 浅色和深色主题均可读；原有操作、反馈、确认和禁用状态保持有效。
